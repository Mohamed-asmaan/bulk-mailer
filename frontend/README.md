# Frontend

React + Vite UI for the Bulk Mailer. Users compose a subject and message, upload an Excel file of recipients, and send everything in one click. Admins can open the history view to see past sends.

**Live app:** [bulk-mailer-seven-mu.vercel.app](https://bulk-mailer-seven-mu.vercel.app/)

## Run locally

```bash
npm install
npm run dev
```

```bash
npm run build     # production bundle
npm run preview   # preview the build locally
```
